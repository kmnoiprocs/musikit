# MusiKit

An interactive, color-coded guide and cheat sheet for everyone who makes music: beatmakers, songwriters, vocalists, rappers, and recording, mixing, and mastering engineers. It is built as an installable web app that works offline.

## Getting started

```bash
npm install
npm run dev               # development server
npm run validate:content  # check all content
npm test                  # validator tests
npm run build             # validate, type-check, build
```
